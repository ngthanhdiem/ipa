Hướng dẫn cài IPA lên iPhone:
1. Tải file IPA về máy tính (PC/Mac)
2. Cài AltStore hoặc Sideloadly trên máy tính
3. Kết nối iPhone với máy tính qua cáp USB
4. Kéo thả file IPA vào công cụ → nhập Apple ID → cài đặt
5. Trên iPhone: Cài đặt → Cài đặt chung → VPN & Quản lý thiết bị → tin tưởng developer
